# Workspace, pages, and folders

The workspace is the home-screen area where application shortcuts, folders,
and standard Android App Widgets are arranged.

## Pages and navigation

- Configure from one to nine workspace pages.
- Choose the default home page.
- Choose a page transition effect and optionally enable looping between the
  first and last workspace pages.
- Use the page overview to navigate or edit the pages, according to the
  selected mode.
- Configure workspace gestures from launcher settings.

## Shortcuts and folders

- Drag shortcuts between workspace pages and compatible docks.
- Arrange shortcuts in folders.
- Organize launchable items with the optional folder app-chain interaction,
  including configurable animation speed and path tracking.
- Lock workspace editing to prevent accidental layout changes while still
  allowing normal application launching.
- When the workspace is locked, existing icons inside an open folder can be
  reordered, but adding or extracting items is restricted.

## Layout and appearance

The launcher's workspace appearance can be adjusted separately from app-drawer
and dock settings. Wallpaper options include Android's system static and live
wallpapers and the launcher's own animated background.

For widget placement, sizing, and provider issues, see [Widgets](widgets.md).
For visual transitions and animated overlays, see [Effects](effects.md).
