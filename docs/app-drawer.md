# App drawer

Open **Launcher settings → App drawer** to customize how installed
applications are displayed and organized.

## Layout and appearance

- **Layout:** vertical list, horizontal pages, or vertical pages.
- **Page looping:** available where the selected layout supports paging.
- **Grid:** configurable from 3 to 10 columns and 3 to 20 rows, with card and
  icon sizes adjusted separately where available.
- **Frames and labels:** adjust icon-frame shape, frame color, opacity, and
  label color.
- **Effects:** configure page-wide effects and individual icon
  transformations.
- **Background:** choose a color, gradient, picture, or system-wallpaper
  background, including supported live-wallpaper arrangements.

## Ordering and moving apps

The drawer supports manual ordering. Long-press an application to begin
reordering, move it across pages, or use the available application actions.
A page-overview hover can switch pages after its on-screen countdown.
The drag hold duration and automatic edge-switch zone width are configurable.

The separate legacy **Move icons** button is not required for the current
unified drag gesture. In paged layouts, an optional inward gesture starting
at the extreme screen edge can interactively switch the workspace page behind
the drawer; this option is disabled by default and is distinct from ordinary
app-drawer page navigation.

## Quick actions and removed applications

The fifth app-drawer bottom-bar button defaults to **Page overview**. It may
instead be assigned to launcher settings, an app-drawer settings subsection,
or one of the supported Android system-settings destinations.

**Keep shortcuts after app removal** is enabled by default. With it enabled,
a removed application may leave a placeholder so its shortcut works again if
the package is reinstalled. When disabled, a real uninstall removes matching
shortcuts from workspaces, docks, and folders. A normal package update is not
treated as an uninstall.

For editing locks and movement between docks and the workspace, see
[Docks](docks.md) and [Workspace](workspace.md).
